# 开发日志

记录真实的开发过程：做了什么、遇到什么问题、怎么修、怎么验证。

## 2026-11-06：第一版跑通

**目标**：把 5 条模拟评论读进来，输出情感分布、主题归因和 Markdown 报告。

**结果**：端到端流程跑通，但抽查发现 C005（1 星差评）被判定为正面。

**排查**：负面词表的权重写成了正数，`sum()` 之后差评反而加分。

**修复**：把正面词表和负面词表分开，合并时统一给负面词取负号。

**验证**：重跑 5 条样本，C005 变为负面，整体风险等级变为「高」。

## 2026-11-07：修正主题误判

**问题**：C002 的“收到货发现袖口有线头”被归因到「物流包装」。

**原因**：物流关键词里有“到货”，而“收到货”包含这两个字。

**修复**：移除歧义关键词；主题归因改为先按标点分句，再在分句内匹配主题和情感词，避免一句话里的多个主题互相污染。

**验证**：C002 的主题变为「质量做工、外观颜色、客服售后」，物流包装不再出现。
